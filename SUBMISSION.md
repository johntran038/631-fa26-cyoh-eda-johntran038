# How this repository works

This repository is your private copy of the assignment.

1. Clone it. The clone lands on the default `work` branch; do all work there.
2. Complete the notebook, restart the kernel, clear output, and run all cells.
3. Commit and push to `work`. If this repository does not yet have a pull request, open one from `work` to `main` in GitHub.
4. Request **`37chandler`** as a reviewer using the **Reviewers** gear. Otherwise I will not be notified that your work is ready.
5. Read feedback on that pull request. **Request changes** means Needs Revision; push fixes to the same branch. Every later push updates the same pull request automatically.
6. **Approved and merged** means Complete.

There is no separate Canvas upload. After the first pull request is open, do not open another one and do not push directly to `main`.
